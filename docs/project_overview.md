* Project Overview

This project is a complete end-to-end ETL (Extract, Transform, Load) data pipeline built using an insurance dataset. It focuses on extracting raw data, transforming it into a clean and structured format, and generating meaningful business insights through SQL analysis and Power BI visualizations.
The pipeline leverages Python for data cleaning, SQL Server for transformation and querying, and Power BI for interactive reporting. The final output is a reliable, analysis-ready dataset that enables data-driven decision-making and uncovers key factors influencing insurance charges.
